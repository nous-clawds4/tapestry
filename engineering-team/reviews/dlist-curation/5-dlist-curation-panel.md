### Non-blocking
1. **`ui/src/pages/grapevine/DListCurationPanel.jsx:118-122`** — `byD` is built with `m.set(e.d, e)` over every kind-39998 entry, so on a Map carrying duplicate `39998:<d>` rows the *last* one decides "In your Map" vs "Replace", while ADR 0002 §5's reader rule is first-occurrence-wins. Reachable only through hand-editing (the writer normalises to one), and Revoke removes every duplicate, so no wrong event can be composed. Optional: `if (!m.has(e.d)) m.set(e.d, e)`. Two identical rows would also collide on `key={coord}` at `:318` (a React warning, not a failure).
2. **`:323-324`** — a kind-39999 entry whose header is found locally links to `/tapestry/lists/<39999:…>`, but `DListDetail.jsx:33` recognises only `39998:` / `9998:` prefixes and would treat the coordinate as an event id → "Event not found". The panel cannot create 39999 entries (out of scope), so this needs a hand-edited Map to reach. Optional: render the link for kind 39998 only, or teach `DListDetail` the 39999 prefix when story 6 gives these entries their links.
3. **`:241`** — AC-4's "marked as such (short pubkey shown)" for the another-assistant state is carried by the Replace control's `title` tooltip; the short pubkey is visible without hovering only in the empowered list's row for the same d-tag, lower in the same panel. Matches the ADR's control-only shape, so not a deviation. Optional: a small inline caption beside "Replace".
4. **`:150-155`** — `created_at` is stamped when the memo computes (at Add / Revoke, or when `event`/hint change), not at Sign & publish; a long pause before signing ships an older-than-now timestamp. The skew rule (`> old.created_at`) still holds, so relays replace correctly; `TlOptInCard.jsx:44-45` chose to recompose at publish time instead. Optional: re-stamp (or recompose) inside `handleSignAndPublish`.
5. **Post-publish behaviour, for the operator's awareness** — `onPublished={search}` nulls the event and sets `loading`, which unmounts the panel; it remounts *folded* with the new count, and the community list is refetched on the next open. 6. **`:159`, `:184`, `:305`** — Add discards a pending Revoke silently (and vice versa), and Cancel clears the pending block but leaves the last error visible until the next action. Cosmetic.
7. **`engineering-team/epics/dlist-curation.md:55-64`** — `## Decisions` lists ADRs 0001–0004; 0005 landed in `ee019420`. Update at the next harness commit (the same gap reviews #1 and #4 noted).
